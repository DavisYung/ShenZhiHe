
########## 8-s2-p1 | 金屬的焰色試驗
進行焰色試驗，化合物中的金屬離子焰色：

| 金屬離子 | 焰色 |
| --- | --- |
| 鉀離子 K⁺ | 淡紫色 |
| 鈉離子 Na⁺ | 金黃色 |
| 鈣離子 Ca²⁺ | 磚紅色 |
| 銅(II) 離子 Cu²⁺ | 藍綠色 |

########## 8-s2-p2 | 氣體檢測（一）：H₂、O₂、CO₂
| 氣體 | 顏色和氣味 | 試驗結果 | 方程式 |
| --- | --- | --- | --- |
| H₂ | 無色、無味 | 燃燒時發出爆鳴聲 | 2H₂(g) + O₂(g) → 2H₂O(l) |
| O₂ | 無色、無味 | 使有餘燼的木條重燃 | / |
| CO₂ | 無色、無味 | 使清澈的石灰水變得乳濁 | Ca(OH)₂(aq) + CO₂(g) → CaCO₃(s) + H₂O(l) |

########## 8-s2-p3 | 氣體檢測（二）：Cl₂、NH₃、HCl
| 氣體 | 顏色和氣味 | 試驗結果 | 方程式 |
| --- | --- | --- | --- |
| Cl₂ | 黃綠色氣體、帶有氯漂白劑的氣味 | 使濕潤的藍色石蕊試紙變紅再漂白（2016） | Cl₂(g) + H₂O(l) ⇌ HCl(aq) + HOCl(aq) |
| NH₃ | 無色、帶有獨特的刺鼻氣味 | 使濕潤的紅色石蕊試紙變藍 | NH₃(aq) + H₂O(l) ⇌ NH₄⁺(aq) + OH⁻(aq) |
| NH₃ | 同上 | 與 HCl(aq) 反應，生成濃密的白色煙霧 | NH₃(g) + HCl(g) → NH₄Cl(s) |
| HCl | 無色、帶有令人窒息的刺鼻氣味 | 與 NH₃(aq) 反應，生成濃密的白色煙霧 | HCl(g) + NH₃(g) → NH₄Cl(s) |

########## 8-s2-p4 | 氣體檢測（三）：SO₂、H₂O
| 氣體 | 顏色和氣味 | 試驗結果 | 方程式 |
| --- | --- | --- | --- |
| SO₂ | 無色、帶有令人窒息的燒硫氣味 | 使一片沾了酸化 K₂Cr₂O₇(aq) 的濾紙由橙色變綠色（2017） | Cr₂O₇²⁻(aq) + 3SO₂(aq) + 2H⁺(aq) → 2Cr³⁺(aq) + 3SO₄²⁻(aq) + H₂O(l) |
| SO₂ | 同上 | 使溴水由棕色變為無色 | SO₂(aq) + Br₂(aq) + 2H₂O(l) → SO₄²⁻(aq) + 2Br⁻(aq) + 4H⁺(aq) |
| H₂O | 無色、無味 | 使乾燥的氯化鈷(II)試紙由藍色變為粉紅色 | / |

########## 8-s3-p1 | 陽離子與 NaOH(aq) 的反應總表
| 溶液中的陽離子 | 加入 NaOH(aq) | 加過量 NaOH(aq) 再溶？ | 加入過量 NH₃(aq) | 加過量 NH₃(aq) 再溶？ |
| --- | --- | --- | --- | --- |
| NH₄⁺ | 與 NaOH(aq) 一起輕微加熱時產生氨 | ✗ | 沒有可觀察變化 | — |
| Ca²⁺ | 白色沉澱 Ca(OH)₂ | ✗ | 沒有可觀察變化 | — |
| Mg²⁺ | 白色沉澱 Mg(OH)₂ | | | |
| Al³⁺ | 白色沉澱 Al(OH)₃ | ✓ | 白色沉澱 Al(OH)₃ | ✗ |
| Zn²⁺ | 白色沉澱 Zn(OH)₂ | ✓ | 白色沉澱 Zn(OH)₂ | ✓（無色溶液） |
| Pb²⁺ | 白色沉澱 Pb(OH)₂ | ✓ | 白色沉澱 Pb(OH)₂(s) | ✗ |
| Fe²⁺（綠色） | 綠色沉澱 Fe(OH)₂ | | | |
| Fe³⁺（黃色） | 紅棕色沉澱 Fe(OH)₃ | | | |
| Cu²⁺（藍綠色） | 淺藍色沉澱 Cu(OH)₂ | ✗ | 淺藍色沉澱 Cu(OH)₂ | ✓（深藍色溶液） |

⚠️ ✓／✗ 指沉澱「能否溶於過量試劑」——這是分辨兩性氫氧化物的關鍵。

########## 8-s3-p2 | 兩性氫氧化物：加過量鹼再溶的鑑別
加入適量 NaOH(aq) 產生白色沉澱後，再加**過量** NaOH(aq)：

- **會再溶（✓）**：Al³⁺ → Al(OH)₃、Zn²⁺ → Zn(OH)₂、Pb²⁺ → Pb(OH)₂
- **不會再溶（✗）**：Ca²⁺ → Ca(OH)₂、Cu²⁺ → Cu(OH)₂、Mg²⁺ → Mg(OH)₂

改加**過量 NH₃(aq)** 時：

- **會再溶（✓）**：Zn²⁺（得無色溶液）、Cu²⁺（得深藍色溶液）
- **不會再溶（✗）**：Al³⁺、Pb²⁺

⚠️ 同一組白色沉澱（Al³⁺／Zn²⁺／Pb²⁺／Ca²⁺／Mg²⁺）必須靠「過量 NaOH」與「過量 NH₃」兩步交叉才可分辨。

########## 8-s3-p3 | 有特徵顏色的陽離子
- **Fe²⁺**：溶液綠色；與鹼生成**綠色沉澱 Fe(OH)₂**
- **Fe³⁺**：溶液黃色；與鹼生成**紅棕色沉澱 Fe(OH)₃**
- **Cu²⁺**：溶液藍綠色；與 NaOH 生成**淺藍色沉澱 Cu(OH)₂**；加過量 NH₃(aq) 後沉澱溶解成**深藍色溶液**
- **NH₄⁺**：與 NaOH(aq) 一起輕微加熱即產生氨（以濕潤紅色石蕊試紙檢驗）
