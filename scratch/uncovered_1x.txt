[1a-s1-p1] 1a / 物質分類總覽 / p2
第一頁章名：**第一章：地球**，開篇給出物質分類框架：

```
物質
├─ 純物質
│   ├─ 元素
│   └─ 化合物
└─ 混合物
```

- 一切物質先分為**純物質**與**混合物**兩大類。
- 純物質再按組成細分為**元素**與**化合物**。

[1a-s2-p2] 1a / 分離空氣中氧和氮的原理 / p4
- 目標：把空氣中的氮、氧、水蒸氣、二氧化碳、氩等成分分離，取出**氮氣與氧氣**。
- ⚠️ **原理：氧和氮具有不同的沸點**——這是整個分餾技術的立足點（氮沸點 −196 ℃、氧沸點 −183 ℃，氮更低先汽化）。
- 方法屬物理變化，沒有新物質生成。

[1a-s4-p2] 1a / 第一步·方法1：傾析法分離海水與泥沙 / p7
第一步目標：把**海水（液體）**與**泥沙（固體）**分離。

- **方法1 傾析法**（OCR 作「析」，即傾析／傾瀉）：
  - 好處：**速度快**；
  - 壞處：**難分離小的固體殘渣**（OCR 作「粗沙處」，不清）；
  - 操作：用**玻璃棒**引流，讓上層液體傾出。

[1a-s4-p4] 1a / 第二步·方法1：蒸發分離食鹽和水 / p8
第二步目標：把**溶質（食鹽）**與**溶劑（水）**分離。

- **方法1 蒸發（取得溶質）**：
  - 好處：**裝置簡單**、**速度快**；
  - 壞處：取得**不純的固體**；
  - 儀器：**蒸發皿**、**鐵絲網**、**三腳架**、加熱。

[1a-s5-p4] 1a / 海水的電解 / p12

- 總反應：**2NaCl(aq) + 2H₂O(l) →(電解)→ Cl₂(g)↑ + H₂(g)↑ + 2NaOH(aq)**（依筆記產物補配平）。

- ⚠️ 水電解正極出氧、海水電解正極出**氯**——別混淆。

[1b-s1-p1] 1b / 元素的定義與分類 / p2
- **元素**：不能以化學方法分解成更簡單的純物質；由相同的原子組成（原子是基本單位），例如銅由銅原子組成。
- 元素按狀態可分為：**氣體、液體、固體**。
- 元素按性質可分為：**金屬、非金屬（及類金屬／半金屬）**。

[1b-s1-p2] 1b / 金屬、非金屬與半金屬的性質比較 / p2
| 類別 | 性質 |
|---|---|
| 金屬（大多數） | ①表面具光澤、堅硬而有強度 ②具延展性 ③良好的導電體和導熱體 ④熔點高及密度高 |
| 非金屬 | ①表面通常暗啞無光 ②不良的導電體和導熱體 ③密度低 |
| 半金屬（類金屬） | ①介乎金屬和非金屬之間 ②半導體［有光澤；結晶可導電；褐色粉末不導電］③易碎 |

⚠️ 教師以「☆大多數」標記金屬性質，提示性質前題是「大多數金屬」，並非全部。

[1b-s1-p4] 1b / 原子序決定元素種類 / p3

- 換言之，質子數目是元素的身份證，決定元素的化學特性。

[1b-s2-p2] 1b / 同位素的定義與性質 / p5
- **同位素**：同一元素的不同原子，它們有**相同的質子數目，但不同的中子數目**。
  - 例：³⁵₁₇Cl 及 ³⁷₁₇Cl
- ☆具**相同的化學性質**（e.g. 氧化性）
- ☆但**不同的物理性質**（e.g. 質量）

[1b-s3-p3] 1b / 電子圖（電子點‑叉圖）的畫法 / p10
- **電子圖**：以圓圈代表電子層、以 × 代表電子，畫出原子的電子排佈。
- 範例：
  - H：電子排佈 1（1 層 1 個電子）
  - K：電子排佈 2,8,8,1（四層）

[1b-s4-p1] 1b / 相同最外層電子數 ⇒ 相似化學性質（同族） / p11
- 如不同元素具有**相同的最外層電子數目** ⇒ 具有**相似**的化學性質。
- e.g. ∵ Na(2,8,1) & K(2,8,8,1) 都含有一粒最外層電子 ∴ **相似的**化學性質（K & Na 都是＿＿＿金屬 —— 即鹼金屬）。
- ⚠️ 這就是「同族元素化學性質相似」的原因（相似，而非相同）。

[1b-s5-p1] 1b / 週期表的排列與橫縱趨勢（P.33） / p13
- **週期表**（課本 P.33）：☆**按質子數目由小至大排列**。
- 主要分族：第 I 族**鹼金屬**、第 II 族**鹼土金屬**、第 VII 族**鹵素**、第 0 族**貴氣體**；中間為**過渡性金屬**。
- 橫向趨勢（由左至右）：**金屬特性↓、吸電子能力↑**；元素由 **金屬 → 半金屬 → 非金屬** 過渡。
- 縱向趨勢：
  - 左邊（第 I 族方向）**活潑性↑**（由上至下遞增）。
  - 右邊鹵素一族**活潑性↑**。
  - 貴氣體一族由上至下：**原子體積↑、放電能力↑**。

[1b-s5-p2] 1b / 同一週期與同一族的比較 / p13
| | 同一週期（e.g. Na & O） | 同一族（e.g. Cl & F） |
|---|---|---|
| 最外層電子數目 | 不相同 | 相同 |
| 被佔用的電子層數目 | 相同 | 不相同 |
| 化學性質 | 不相同 | 相似（e.g. Cl₂ & F₂ 也能與 AgNO₃/H⁺ 生成沉澱物） |

⚠️ 同週期＝電子層數相同、最外層不同；同族＝最外層相同、電子層數不同 → 故同族化學性質相似。

[1b-s5-p3] 1b / 鹼金屬（第 I 族）的性質（P.41） / p14
- **鹼金屬（第 I 族）**（P.41）：
  - **熔點及沸點**由上至下依次遞減，並相比其他族的金屬較低。
  - **軟金屬**。
  - **密度低**［能浮於水面］。
  - **活潑金屬，需存於石蠟油中**。
  - 化學性質相似，**活潑性由上至下依次遞增**；e.g. 與水反應生成**鹼性溶液及氫**。

[1b-s5-p6] 1b / 貴氣體（第 0 族）的性質 / p15
- **貴氣體（第 0 族）**（課本 P.52）：
  - **熔點、沸點和密度**由上至下依次**遞增**（但整體都很低）。
  - **熔點和沸點都很低**。
  - 常溫常壓下是**無色氣體**。
  - **極不活潑**（最外層電子已達穩定排佈，不易起反應）。

[1b-s6-p1] 1b / 離子的定義與陽離子、陰離子 / p17
- **離子**
  - 原子藉化學反應**獲得或失去電子**，以達到像**貴氣體的穩定電子排佈**。
  - 帶**正或負電荷**。
- **陽離子 — 原子失去電子**；☆多數是**金屬**。
  - e.g. 鈉原子 → 鈉離子 ＋ e⁻（Na → Na⁺ + e⁻，鈉原子失去最外層1個電子）。
- **陰離子 — 原子獲得電子**；☆多數是**非金屬**。
  - e.g. 氯原子 ＋ e⁻ → 氯離子（Cl + e⁻ → Cl⁻，氯原子獲得1個電子）。

[1b-s6-p3] 1b / 用電子結構圖解釋離子的形成過程 / p18
利用電子結構圖［**只顯示最外層電子**］，解釋原子變成離子的過程：

1. **Na**：2,8,1 → ［Na］⁺ ＋ e⁻（Na⁺ 為 2,8）
2. **Mg**：2,8,2 → ［Mg］²⁺ ＋ 2e⁻（Mg²⁺ 為 2,8）

- 畫法：原子只畫最外層電子（×），失去電子時以方括號 ［］包住離子並在右上角標電荷，旁邊寫「＋ ne⁻」。

[1b-s6-p4] 1b / 八隅體規則與穩定結構 / p16
- **八隅體**：原子的**最外層電子數目為 8**，便能達致穩定。
- **雙隅體**：第一週期的原子（如 H、He）最外層只需 **2 個電子**即達穩定。
- **Remark**：若原子與其中一種**貴氣體原子的電子排佈相同**，該原子會變得穩定（例：Na 失去 1 個電子後排佈與 Ne 相同 ⇒ Na⁺ 穩定）。
- ⚠️ 教師重點：透過**週期表可推測新生元素的性質**——物理性質（熔點、沸點、密度、味道、顏色、水溶性）、化學性質（活性、氧化性）。

[1b-s7-p2] 1b / 例1：氯化鈉的形成過程 / p21
1. **鈉原子**（2,8,1）失去 1 個電子 → **鈉離子 Na⁺**（2,8）：Na → Na⁺ + e⁻
2. **氯原子**（2,8,7）得到 1 個電子 → **氯離子 Cl⁻**（2,8,8）：Cl + e⁻ → Cl⁻
3. Na⁺ 與 Cl⁻ 以**離子鍵**結合成 NaCl。
4. **電荷校驗**：總電荷 = (+1) + (−1) = 0（化合物呈電中性）。
- ⚠️ 教師重點：畫電子式時Na 失去的電子要畫到 Cl 上，並標明離子電荷。

[1b-s8-p1] 1b / 多原子離子與常見離子的顏色 / p23
- **多原子離子**：由**兩個或以上的原子**組成的帶電粒子。
- 常見多原子離子：氫氧根 **OH⁻**、硝酸根 **NO₃⁻**、碳酸根 **CO₃²⁻**、硫酸根 **SO₄²⁻**、銨 **NH₄⁺**。
- 區分：**化學式**（電中性）如 NaCl、MgO、Al₂O₃；**離子式**（帶電）如 Na⁺、SO₄²⁻、NH₄⁺。
- 常見離子顏色（水溶液）：Cu²⁺ **藍**、Fe²⁺ **淺綠**、Fe³⁺ **黃**、Cr³⁺ **綠**、Ni²⁺ **綠**、Cr₂O₇²⁻ **橙**、Mn²⁺ **近乎無色**、MnO₄⁻ **紫**。
- ⚠️ 教師重點：過渡金屬離子多有顏色，是定性分析的重要線索。

[1b-s8-p3] 1b / 離子的命名規則 / p25
**陽離子的命名**：
- 第 I、II、III 族元素：名稱＋**離子**（如鈉離子、鎂離子、鋁離子）。
- 有些金屬（主要是**過渡金屬**）能產生多於一種離子 ⇒ 用**電荷數目**（羅馬數字）區分：Cu⁺ **銅(I)離子**、Cu²⁺ **銅(II)離子**。

[1b-s9-p1] 1b / 分子的定義與分類 / p28
- **分子**：一個或一組能在常溫常壓下**獨立存在的原子**。
- 依原子數分類：**單原子分子**（He、Ne）、**雙原子分子**（N₂、O₂、H₂、Cl₂）、**三原子分子**（H₂O、CO₂、SO₂）。
- 由同種元素的原子組成的單質稱**分子元素**；由不同元素的原子組成的化合物稱**分子化合物**。

[1b-s9-p4] 1b / 電子圖：氯化氫與四氧（甲）烷 / p30
- **氯化氫 HCl**：鍵合電子對 = **1 對**，孤電子對 = **3 對**（每個原子各 1 對，氫不計孤電子對）。
- **四氧甲烷 CH₄**（OCR 作「四氧甲烷」）：鍵合電子對 = **4 對**，孤電子對 = **12 對**（每個碳原子 3 對，共 4 個碳原子）。
- 電子圖只顯示**最外層電子**，內層電子省略不畫。

[1b-s11-p1] 1b / 配位共價鍵的定義 / p33
- **配位共價鍵**：一種由**一個原子獨自提供整對鍵合電子**的共價鍵。
- 與普通共價鍵的分別：普通共價鍵由兩粒原子**各提供一粒電子**；配位共價鍵的兩粒電子**全部來自同一個原子**。
- 鍵形成後與普通共價鍵無異，因此形成後的粒子不再區分「配位鍵」與「共價鍵」。

- **相對分子質量**：該元素或化合物**一個分子內所有原子的相對原子質量總和**。
- 是一個**比值**，因此**沒有單位**。
- 適用於有獨立分子的物質（分子元素、分子化合物）。
- ⚠️ 教師重點：只可用於**分子物質**，離子化合物沒有獨立分子，不能用此定義。

[1b-s13-p1] 1b / 巨型離子結構的組成與 bonding / p35
- 由**離子化合物**構成，**陰陽離子**以**強大的離子鍵**連結成**三維晶格（巨型）**結構。
- 每粒離子同時被多個**異號離子**包圍，**沒有獨立的分子**，故稱「巨型」。
- 適用例子：**氯化鈉、氧化鎂**等由金屬與非金屬化合生成的化合物。

[1b-s13-p4] 1b / 氯化鈉 NaCl 的結構圖 / p35

- 每個 Na⁺ 被多個 Cl⁻ 包圍，每個 Cl⁻ 亦被多個 Na⁺ 包圍，整體呈**立體晶格**。
- ⚠️ 教師重點：巨型離子結構畫的是**結構單元**（離子標示＋離子鍵），不是分子；化式單位為 NaCl。

[1b-s14-p1] 1b / 巨型共價結構的特徵 / p36
- 由**共價化合物**組成，例如**碳 C**（石墨、鑽石）、**矽 SiO₂**（石英）。
- **高熔點及高沸點**（原子間以強的共價鍵連結成三維網狀結構）。
- **不溶於任何溶劑**。
- **不導電**，因為沒有可自由流動的離子或電子（**石墨除外**）。

[1b-s15-p1] 1b / 同素形體的定義 / p38
- **同素形體**：同一種元素的原子或分子以**兩種或以上不同的方式排列**所形成的不同結構。
- 例子：**碳**有**金剛石**與**石墨**兩種同素形體。
- ⚠️ 教師重點：同素形體是「**同一元素、不同排列**」，不是化合物，成分完全相同。

[1b-s15-p4] 1b / 石墨的應用 / p40
- ①**耐火產品**（如坩堝／模具）：可抵受高溫，因熔點極高。
- ②**電極**：利用石墨良好的**導電性**（化學惰性，較耐化學侵蝕）。
- ③**潤滑劑**：利用層間微弱的**范德華引力**，層易滑過，產生滑膩感。
- ④**鉛筆芯**（黏土與石墨混合）：利用其**滑膩感**及深色留下痕跡的特性。

[1b-s16-p1] 1b / 簡單分子結構的特徵 / p41
- 由**共價化合物**組成，例如 **H₂、O₂、CO₂、N₂**；由**獨立的分子**存在。
- **低熔點及低沸點**，因為分子間只有**微弱的范德華引力**。
- **大部分不溶於水**，一般可溶於非水溶劑。
- **不導電**，因為沒有可自由流動的電子或離子。

[1b-s17-p1] 1b / 物質類別 → 結構類別的對應 / p42
- **離子化合物 → 巨型離子結構**。
- **共價化合物 → 巨型共價結構**（如金剛石、二氧化矽）或**簡單分子結構**（如水、氨）。
- **金屬／合金 → 巨型金結構**。
- ⚠️ 教師重點：判斷入口是先問「這物質由什麼組成」——金屬＋非金屬 → 離子；非金屬之間 → 共價（巨型或簡單）；金屬 → 巨型金。

[1b-s18-p1] 1b / 結構類別、在哪裡形成與所含粒子 / p43
- **巨型離子結構**：由**金屬和非金屬**化合生成的化合物，如**氯化鈉、氧化鎂**；所含粒子為**陽離子和陰離子**。
- **巨型共價結構**：由**第 IV 族元素及部分非金元素**化合生成，如**金剛石、石墨、二氧化矽**；所含粒子為**原子**。
- **簡單分子結構**：由**一些非金元素**化合生成，如**氫、碘、氨、乾冰**；所含粒子為**細小的分子**。
- **巨型金屬結構**：由**金屬**生成，如**銅、鎳**；所含粒子為**帶正電荷的金屬離子**，被**離域電子海**包圍。

[1b-s18-p2] 1b / 化學鍵與常溫常壓下的狀態 / p43
- **巨型離子**：由**強大的離子鍵**連結；常溫常壓下為**固體**。
- **巨型共價**：原子藉**強大的共價鍵**連結成三維網狀結構；常溫常壓下為**固體**。
- **簡單分子**：分子內為強大的共價鍵，**分子之間只有微弱的范德華力**；常溫常壓下可呈**固體、液體或氣體**（如乾冰為固體、水為液體、氧氣為氣體）。
- **巨型金屬**：由**強大的金屬鍵**連結；常溫常壓下為**固體**。

- ☆44.0 g 有 6.02×10²³ 粒 CO₂ 分子

**離子化合物**（例：氯化鉀 KCl）

- ∴ KCl 的摩爾質量是 74.5 g mol⁻1

[1c-s8b-p3] 1c / 質量與粒子數目的換算（三角關係） / p21

[1c-s11-p4] 1c / 限量反應物例題 2（氨的氧化） / p30
**e.g.2 3.23 g 的氨與 2.88 g 的氧反應後會生成一氧化氮及水：(i) 生成多少質量的一氧化氮；(ii) 剩餘多少質量的反應物？**（H = 1.0, O = 16.0, N = 14.0）

- 4NH₃(g) + 5O₂(g) → 4NO(g) + 6H₂O(l)；已知 3.23 g（NH₃）、2.88 g（O₂）
- NH₃ 的摩爾數 = 3.23 ÷ (14.0 + 1.0×3) = 0.19 mol
- O₂ 的摩爾數 = 2.88 ÷ (16.0×2) = 0.09 mol
- ∵ O₂ 的摩爾數 ÷ 5 < NH₃ 的摩爾數 ÷ 4 ⇒ **O₂ 是限量反應物**
- (i) NO 的摩爾數 = (0.09 ÷ 5) × 4 = 0.072 mol；NO 的質量 = 0.072 × (16.0 + 14.0) = **2.16 g**
- (ii) 已反應的氨的摩爾數 = (0.09 ÷ 5) × 4 = 0.072 mol；剩下的氨的摩爾數 = 0.19 − 0.072 = 0.118 mol；剩下的氨的質量 = 0.118 × (14.0 + 1.0×3) = **2.006 g**

[1c-s12-p3] 1c / 例題 (b)：求氨的實際產量 / p31
(b) 氨的百分產率是 15%，氨的實際產量是多少？

- 實際產量 = 理論產量 × 百分產率 = 4420 × 15% = **663 g**

[1c-s13-p1] 1c / 腐蝕的定義與鐵的生鏽 / p32
- **腐蝕 = 金屬與水、氧或其他物質的反應。**
- ☆較活潑的金屬腐蝕速度比較快。

**鐵的腐蝕（稱為生鏽）**
- ⚠️ 條件：**氧和水同時存在**
- 方程式：**4Fe(s) + 3O₂(g) + 2nH₂O(l) → 2Fe₂O₃·nH₂O(s)**
- 鐵鏽 = 水合氧化鐵(III)（紅棕色）
- 鐵鏽**會不斷漲大並容易碎裂**（不能保護內層的鐵）。

[1c-s13-p3] 1c / 加快生鏽速率的五個因素 / p34
① 溫度上升
② 存在離子化合物〔如：氯化鈉〕
③ 存在酸性污染物〔工廠排出酸性氣體〕
④ 經刮擦或形狀呈凹凸扭曲（☆增加金屬表面與空氣及水接觸的面積）
⑤ 與活潑性較低的金屬接觸

[1c-s13-p4] 1c / 使用鐵鏽指示劑觀察鐵的鏽蝕 / p35
- **指示劑 = 六氰合鐵(III)酸鉀 K₃Fe(CN)₆ 和酚酞的混合物**（混在膠凝體中）
- K₃Fe(CN)₆：**藍色 ⇒ Fe²⁺ 離子**（即有 Fe²⁺ 生成，表示鐵被氧化）
- 酚酞：**粉紅色 ⇒ OH⁻ 離子**

生鏽的探究〔不理會酚酞〕：
- (a) 鐵釘：正常情況
- (b) 弯折的鐵釘：形狀改變
- (c) 鐵釘繞銅線：∵ 鐵釘與活性較低的銅接觸 ∴ **鏽蝕速度↑**（藍色出現）
- (d) 鐵釘繞鎂帶：∵ 鐵釘與活性較高的鎂接觸 ∴ **防止鐵腐蝕**（鎂被腐蝕，保護鐵）

[1c-s13-p7] 1c / 鋁的抗腐蝕能力與陽極電鍍 / p38
**鋁的抗腐蝕能力**
- 鋁的表面與氧反應生成一層**均勻、惰性、堅固及不透水/氧的氧化鋁**，防止鋁發生腐蝕（即使鋁的活性頗高）。

**鋁的陽極電鍍**
- 作用：① 加厚氧化層 ② 使氧化層變得更均勻
- 實驗裝置：電解質為**稀硫酸 H₂SO₄**；圖中電極標註為「鋁片（負電極）」與「接受陽極電鍍的鋁製品（正電極）」（原頁 (+)/(−) 接線與標籤對應位置較模糊）
- ⚠️ 陽極電鍍時鋁製品接正電極（陽極），氧化層在鋁表面生成。
