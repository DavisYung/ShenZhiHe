
########## 8-s4-p1 | 鹵素離子：加入酸化 AgNO₃(aq)
| 陰離子 | 試驗結果 | 方程式 |
| --- | --- | --- |
| 氯離子 Cl⁻ | 白色沉澱 | Ag⁺(aq) + Cl⁻(aq) → AgCl(s) |
| 溴離子 Br⁻ | 淺黃色沉澱 | Ag⁺(aq) + Br⁻(aq) → AgBr(s) |
| 碘離子 I⁻ | 黃色沉澱 | Ag⁺(aq) + I⁻(aq) → AgI(s) |

試劑：加入**酸化 AgNO₃(aq)**。三種沉澱的顏色由淺至深：白 → 淺黃 → 黃。

########## 8-s4-p2 | 次氯酸根離子 OCl⁻
- 加入酸化 AgNO₃(aq) 一欄中，OCl⁻ 的試驗結果為：釋出**黃綠色的氣體 Cl₂**，使濕潤的**藍色石蕊試紙變成紅色，然後把它漂白**。
- 方程式：OCl⁻(aq) + Cl⁻(aq) + 2H⁺(aq) → Cl₂(g) + H₂O(l)

########## 8-s4-p3 | 碳酸根 CO₃²⁻ 與亞硫酸根 SO₃²⁻：加入稀 HCl(aq)
| 陰離子（固體或溶液） | 試驗結果 | 方程式 |
| --- | --- | --- |
| 碳酸根 CO₃²⁻ | 發生泡騰／釋出的無色氣體使清澈的石灰水變得乳濁 | CaCO₃(s) + 2H⁺(aq) → Ca²⁺(aq) + CO₂(g) + H₂O(l) |
| 亞硫酸根 SO₃²⁻ | 帶有令人窒息的燒硫氣味的氣體；使一片沾了酸化 K₂Cr₂O₇(aq) 的濾紙**由橙色變綠色**（2017） | SO₃²⁻(aq) + 2H⁺(aq) → SO₂(g) + H₂O(l) |

⚠️ 同樣加稀 HCl，靠氣體的檢驗（石灰水 vs 酸化 K₂Cr₂O₇ 濾紙）來分辨 CO₃²⁻ 與 SO₃²⁻。

########## 8-s5-p1 | 碳-碳雙鍵 (C=C) 的檢驗
| 試驗結果 | 方程式 |
| --- | --- |
| (b) 使溶於 CH₂Cl₂ 的棕色 Br₂ 脫色（2012PP） | CH₂=CH₂ + Br₂ → CH₂BrCH₂Br |
| (ii) 使 MnO₄⁻(aq)/H⁺(aq) 由紫色變為無色 | CH₂=CH₂ + [O] + H₂O → CH₂(OH)CH₂(OH) |

⚠️ 老師以乙烯為例；(i) 溴的四氯化碳/二氯甲烷溶液脫色與 (ii) 酸性高錳酸鉀褪色是 C=C 的兩個經典檢驗。

########## 8-s5-p2 | 羥基 (–OH) 的檢驗
(i) 1° 或 2° 醇與 Cr₂O₇²⁻(aq)/H⁺(aq) 一起加熱時，**溶液由橙色變為綠色**：

```
3CH₃CH₂OH(aq) + 2Cr₂O₇²⁻(aq) + 16H⁺(aq) --加熱--> 3CH₃COOH(aq) + 4Cr³⁺(aq) + 11H₂O(l)
```

(ii) 在濃 H₂SO₄(l) 下，與羧酸一起加熱時會**發出怡人果香氣味**（酯化反應）。

########## 8-s5-p3 | 醛和酮的羰基 (C=O) 與醛的 –CHO 基
- **羰基 C=O**：與 2,4-二硝基苯肼溶液反應，生成**黃色或紅色沉澱**（2,4-二硝基苯腙沉澱）（2012）。
- **醛的 –CHO 基**：與托倫斯試劑共熱，得出**銀鏡**（2019）：

```
CH₃CHO + 2Ag(NH₃)₂⁺ + 3OH⁻ --加熱--> CH₃COO⁻ + 2Ag↓(銀鏡) + 4NH₃ + 2H₂O
```

⚠️ 2,4-二硝基苯肼同時檢測醛和酮；托倫斯試劑（銀鏡）只檢測醛。

########## 8-s5-p4 | 羧基 (–COOH) 的檢驗
在濃 H₂SO₄(l) 下，把羧酸與醇一起加熱時，生成**帶有獨特怡人果香氣味的酯**。

⚠️ 與羥基檢驗 (ii) 是同一反應的兩個說法（醇 + 羧酸 ⇌ 酯 + 水），濃 H₂SO₄ 作催化劑並吸水。
