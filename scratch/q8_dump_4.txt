
########## 8-s8-p1 | 莫爾法（Mohr's method）測定 [Cl⁻(aq)]
- **例子**：莫爾法測定溶液中的 [Cl⁻(aq)]
- **滴定劑**：標準 AgNO₃(aq)
- **指示劑**：K₂CrO₄(aq)

反應進行時 ⇨ [Cl⁻(aq)] ↓：

```
Ag⁺(aq) + Cl⁻(aq) → AgCl(s)  白色沉澱
```

反應完結後 ⇨ [Cl⁻(aq)] 已完全反應：

```
2Ag⁺(aq) + CrO₄²⁻(aq) ⇌ Ag₂CrO₄(s)  紅棕色沉澱
```

**＊滴定終點：生成紅棕色沉澱**

########## 8-s8-p2 | ⚠️ 莫爾法為何不可酸化
**＊AgNO₃(aq) 無需酸化**，否則指示劑會與 H⁺ 反應生成 HCrO₄⁻ 或 Cr₂O₇²⁻，令 CrO₄²⁻ 濃度改變、終點判斷失準。

⚠️ 這是莫爾法最常考的陷阱：別把「酸化 AgNO₃」用在莫爾法上（酸化 AgNO₃ 是用於鹵素離子的定性檢驗）。

########## 8-s8-p3 | 例題 3：計算水樣本中 Cl⁻ 濃度
陳學生用 0.050 mol dm⁻³ 硝酸銀溶液滴定 10.0 cm³ 水樣本，終點時用了 52.00 cm³ 硝酸銀溶液。

- (a) 指示劑：**鉻酸鉀溶液**
- (b) 終點判斷：**達致終點時，有紅棕色沉澱出現**
- (c) 計算：

```
Ag⁺(aq) + Cl⁻(aq) → AgCl(s)
與 Cl⁻ 反應的 Ag⁺ 摩爾數 = (0.050 × 52.00)/1000 = 2.6 × 10⁻³ mol
水樣本中 Cl⁻ 濃度 = 2.6 × 10⁻³ ÷ (10.00/1000) = 0.26 mol dm⁻³
```

########## 8-s9-p1 | 碘量法原理與例子
- **涉及 I₂(aq) 的氧化還原滴定**：I⁻(aq) 適用於測定**中等強度的氧化劑**
- **例子**：測定氯漂白劑中 [OCl⁻(aq)]（有效成分）

**滴定步驟 1**：把過量 KI(aq) 及過量 H₂SO₄(aq) 加入到經稀釋的漂白劑樣本中反應：

```
OCl⁻ + 2I⁻ + 2H⁺ → Cl⁻ + I₂ + H₂O
反應物均無色                I₂ 棕色
```

########## 8-s9-p2 | 滴定步驟 2：硫代硫酸鈉滴定與澱粉指示劑
- **滴定劑**：標準硫代硫酸鈉溶液 Na₂S₂O₃(aq)
- **指示劑**：澱粉溶液

```
I₂(aq) + 2S₂O₃²⁻(aq) → 2I⁻(aq) + S₄O₆²⁻(aq)
深藍色                      無色
```

**＊滴定終點：溶液由深藍色變成無色**

**＊須先滴定部分 I₂(aq)**：當溶液變為**淺黃色**，再加入指示劑 ⇨ 否則 I₂(aq) 與澱粉反應 ⇨ 測定的 I₂(aq) 的量減少。

⚠️ 考試陷阱：澱粉不能一開始就加，要等溶液變淺黃色才加。

########## 8-s9-p3 | 計算步驟四步鏈（稀釋 → 原來樣本）
① 利用 S₂O₃²⁻ 摩爾數 → ② 找出 I₂ 摩爾數 → ③ 找出 I⁻(aq) 摩爾數 → ④ 找出 OCl⁻ 摩爾數（**經稀釋**）→ 再推回 OCl⁻ 摩爾數（**原來樣本**）。

⚠️ 最後一步記得乘回稀釋倍數（例如 25.0 cm³ 取自 250.0 cm³，要 ×10）。

########## 8-s9-p4 | 例題 4：「Big 蓮」氯漂白劑 [OCl⁻] 測定
步驟一：用蒸餾水把 25.0 cm³ 漂白劑樣本稀釋至 250.0 cm³；步驟二：取 25.0 cm³ 已稀釋樣本至錐形瓶，加過量 KI(aq) 及過量 H₂SO₄；步驟三：用 0.100 mol dm⁻³ Na₂S₂O₃(aq) 滴定，澱粉作指示劑。

- (a) 稀釋操作：把 25.0 cm³ 漂白劑樣本注入容量瓶，加蒸餾水至 250.0 cm³ 刻度。
- (b) 終點檢測：溶液由深藍色變為無色。
- (c) 已知 Na₂S₂O₃ 平均體積 20.50 cm³，計算 [OCl⁻(aq)]（注意 ×10 稀釋倍數）。
- (d) 強酸性下副反應：S₂O₃²⁻(aq) + 2H⁺(aq) → SO₂(g) + S(s) + H₂O(l)；題目要求指出該副反應對測定 [OCl⁻] 的影響（參考文字檔未附答案）。
