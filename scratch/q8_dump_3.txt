########## 8-s6-p2 | 重點方法 (a)：再結晶法
1. 將固體生成物完全溶解在**最小量的熱溶劑**中。
2. 過濾熱溶液並慢慢冷卻混合物，使目標物質結晶析出。

- 配套裝置：**吸濾法**（抽氣過濾）加快過濾與乾燥。

⚠️ 關鍵字「最小量的熱溶劑」與「慢慢冷卻」——溶劑太多或冷卻太快都會降低回收率。

########## 8-s6-p3 | 重點方法 (b)：液液萃取法
- ＊選用溶劑**不能與含生成物的溶劑互溶**
- ＊生成物的溶解度：**溶劑 ＞ 反應混合物**
- 儀器：**分液漏斗**

⚠️ 兩個條件缺一不可：互不相溶才會分層；溶解度較大才會把目標物萃取到新溶劑中。

########## 8-s6-p4 | (c) 色層法：分離原理與紙色層法
**分離原理**：不同物質在固定相上具不同的吸附率，它們在流動相中有不同的溶解度。（2019）

- 固定相：保持靜止；流動相：在固定相中移動（常用：戊烷、丙酮和乙醇）
- 成分愈溶於溶劑（流動相）⇨ 移動得愈快
- 成分被固定相吸附得愈強 ⇨ 移動得愈慢

**(i) 紙色層法**步驟：① 濾紙上用鉛筆畫基線、點上樣本點 → ② 放入盛有溶劑（e.g. 乙醇、丙酮）的燒杯並加蓋 → ③ 幾分鐘後取出，量度斑點與溶劑前沿的移動距離。

$$比移值(R_f) = \frac{成分所移動的距離}{溶劑所移動的距離}$$

- Rf 值：物質移動距離對溶劑前端移動距離的比值（2018）
- 在特定條件下使用特定溶劑，比較實驗值與數據冊所載的 Rf ⇨ 辨認未知成分

########## 8-s6-p5 | 薄層色層法、柱色層法與色層法總結表
- **(ii) 薄層色層法**：與紙色層法的進行步驟幾乎相同（薄層色層片為 Al₂O₃ / SiO₂，以展開劑展開）。
- **(iii) 柱色層法**：可作分離、定量分析和鑑定化合物（洗提溶劑為流動相，硅膠或礬土為固定相，底部墊玻璃棉）。

| 色層法 | 固定相 | 流動相 | 分離和鑑定 | 獲取成分 |
| --- | --- | --- | --- | --- |
| 紙色層法 | 附在濾紙纖維上的水 | 液體溶劑 | ✓ | |
| 薄層色層法 | 硅膠(SiO₂)或礬土(Al₂O₃)粉末 | 液體溶劑 | ✓ | |
| 柱色層法 | 硅膠或礬土 | 液體溶劑（洗提溶劑） | ✓ | ✓ |

⚠️ 只有**柱色層法**可以「獲取成分」（把分離後的成分實際收集成溶液），紙色層與薄層只作分離和鑑定。

########## 8-s7-p1 | 滴定的四大類別與例子
| 滴定類別 | 例子方程式 |
| --- | --- |
| 酸鹼 | HCl + NaOH → NaCl + H₂O |
| 酸和碳酸鹽 | 2HNO₃ + Na₂CO₃ → 2NaCl + H₂O + CO₂ |
| 沉澱 | AgNO₃ + NaCl → AgCl + NaNO₃ |
| 氧化還原 | 2MnO₄⁻ + 5SO₃²⁻ + 6H⁺ → 2Mn²⁺ + 5SO₄²⁻ + 3H₂O |

⚠️ 參考文字檔中「酸和碳酸鹽」一欄作 2HNO₃ + Na₂CO₃ → 2NaCl + H₂O + CO₂（pdftotext 抽出，生成物可能為排版錯植，此處按原文照錄）。

########## 8-s7-p2 | 容量分析的條件（2019）
1. 限量反應物被耗盡時，要**容易觀察到變化**（有適當指示劑）
2. 反應必須**很大程度地完成**
3. 反應**速率必須足夠快**

########## 8-s7-p3 | 滴定誤差與減低誤差的方法
- **滴定誤差來源**：儀器、化學品導致的不確定性；不當的實驗技巧 —— ＊**不能避免**
- **減低誤差的方法**：增加重複滴定數次，並取合理平均體積
